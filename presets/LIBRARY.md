# Selected patch library

All 26 active patches are stored directly in `presets/user/`, the folder used by the desktop patch selector and Save As. All use the fixed 24 dB/octave low-pass Model D engine. The six former 18 dB patches were retuned to approximate their earlier sound; the other 20 are unchanged.

Model D mode defaults to Moog Res. Historical factory and research presets elsewhere in this repository are not part of the active library.
